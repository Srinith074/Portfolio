# Srinith portfolio — Next.js
Requires Node.js 20.9+ (22 LTS recommended). Run `npm install`, then `npm run dev` and open http://localhost:3000. Run `npm run build` before deploying. Deploy as a Next.js project on Vercel, not the old static GitHub Pages workflow. Keep the old project until verified. Public configuration is in data.json; no secrets needed. Place real project screenshots in public/projects with filenames from data.json. Replace public/resume.pdf and bump the query version in components/ui.tsx when updating. Certificates are resume-listed, verification links not supplied. Test contact delivery, mobile Safari PDF open/download, theme, filters and external links before switching the domain. Social preview is retained from the previous portfolio.
